# vTubeArea

**Твоё лицо, твои руки, твой аватар. Вживую, без интернета, бесплатно.**

Десктопная студия для VTuber: 2D-аватар повторяет лицо и каждый палец по обычной вебкамере,<br />
эмоции на горячих клавишах, сцена с фоном и предметами, и ничего не уходит с компьютера.

## ✦ Быстрый старт

```bash
pnpm install
pnpm setup:assets      # MediaPipe и модели лица и рук, один раз
pnpm dev               # десктоп-приложение
```

> **Нужно**: Node 22+, pnpm 10, Rust 1.90+. На macOS — Xcode Command Line Tools, на Windows — WebView2 (есть в Windows 11).

При первом запуске ставятся три тестовые модели: **Lumi**, **Kuro** и **Haru**. Дальше:

1. **Трекинг → Включить**, посмотрите прямо в экран, нажмите **Калибровать**.
2. **Трекинг → Руки** — включить трекинг рук.
3. **Сцена** — фон и предметы.
4. Скройте интерфейс и захватите окно в OBS.

<details>
<summary><b>Стрим через OBS</b></summary>
<br />

- **macOS**: «Захват окна» vTubeArea. Для прозрачного аватара выберите **Сцена → Фон → Нет**, OBS сохранит альфа-канал.
- **Windows**: захват прозрачности ненадёжен; выберите **Сцена → Фон → Хромакей** и добавьте в OBS фильтр «Хромакей» с тем же цветом.

</details>

<details>
<summary><b>Горячие клавиши</b></summary>
<br />

| Действие | macOS | Windows / Linux |
| --- | --- | --- |
| Скрыть / показать интерфейс | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>H</kbd> |
| Режим отладки | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>D</kbd> |
| Калибровка | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>K</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>K</kbd> |

Переназначаются в **Настройки → Клавиши**, у эмоций свои клавиши в **Модели → Эмоции**.
Кнопка 🌐 делает сочетание глобальным — оно работает, даже когда приложение свёрнуто.

</details>

<details>
<summary><b>Про камеру</b></summary>
<br />

Предел задаёт камера: встроенная FaceTime HD у MacBook даёт 1280×720 при 30 FPS, iPhone как Continuity Camera —
1080p при 60 FPS. В **Трекинг → Камера** показаны только режимы, которые умеет ваша камера.
Выше 720p трекинг почти не улучшается; больше помогает, только если сидеть далеко от камеры.

</details>

## ✦ Свой аватар

Модели в открытом и читаемом формате: папка с `model.json` и картинками PNG, WebP или SVG.
Слои, группы, привязки параметров, маски, физика пружин, эмоции, руки и руки целиком описаны
в [`packages/model-format/SPEC.md`](packages/model-format/SPEC.md).
Добавить модель — **Модели → Добавить модель** или перетащите папку в окно.

> Модели Live2D `.moc3` не поддерживаются: формат закрытый и требует проприетарного SDK Live2D.

<br />

## ✦ Как устроено

```
apps/desktop          Tauri 2 · React · PixiJS        приложение (UI + ядро на Rust)
packages/protocol     FaceFrame                        единый формат трекинга для всех источников
packages/model-format схема · валидатор · SPEC         формат аватара
packages/engine-2d    рендер на PixiJS                 параметры на входе, картинка на выходе
packages/ui           дизайн-система · RU/EN           общие компоненты
assets/sample-models  Lumi, Kuro, Haru                 генерируются из кода
```

Трекинг — MediaPipe Face и Hand Landmarker локально; все источники идут в один трекинг-хаб, так что
трекер на телефоне подключится позже без изменений на стороне аватара. Внешнее управление (ИИ-агент, MCP,
плагины) — через единый `AvatarControlPort`. Подробности в [`docs/architecture`](docs/architecture).

```bash
pnpm check             # линтер + типы + тесты (TypeScript и Rust)
```
